# 视界Box

一款 Android TV / 手机端影视播放应用。支持多仓聚合、聚合搜索、源健康度探测、
Exo / MPV 双播放内核，TV 遥控器与手机触屏双 UI。

## 功能

### 多仓聚合

已保存的多个仓库配置可同时生效，站点表合并展示，无需来回切换。

- 设置 → 多仓聚合 一键开关（显示当前附仓数量）
- 按 `site.key` 去重，主仓优先；每个站点自带 spider，不同仓互不干扰
- 单个仓加载失败只跳过该仓，不影响主配置

### 源健康度探测

- 站点列表每个源带状态点：灰=未检测，绿=可用，红=不可用
- 打开站点列表时自动巡查过期源（24 小时有效期），8 路并发、单源 8 秒超时
- 聚合搜索按健康度排序：可用 → 未检测 → 不可用，同档按延迟升序

### 聚合搜索

- 多源并发搜索，结果页左侧源筛选纵向排列，右侧海报墙
- 跨源同名条目自动去重（全半角、括号说明、清晰度后缀归一化）
- 搜索页内置电视榜 / 电影榜 / 综艺榜 / 儿童榜分组热词，点词即搜

### 双播放内核

- ExoPlayer 默认内核，兼容绝大多数在线源
- MPV 内核（捆绑 FFmpeg + libass）兜底非常规封装，设置 → 播放器 一键切换
- 播放失败自动切换另一内核重试一次

### 首页

- 「主页」弹出源选择（带健康状态点），右侧紧跟当前源分类，点分类即切换
- 分类浏览纯海报墙铺满全屏，下滑翻页
- 搜索 / 直播 / 历史 / 收藏 / 推送 / 本地 / 配置 / 设置 常驻顶栏

## 构建

1. Android Studio 或 Gradle 9.x + JDK 21
2. Python 3.10（NuGet 完整版，需含 venv 模块），路径配置于 `chaquo/build.gradle`
3. NDK，双 ABI（arm64-v8a、armeabi-v7a）与 x86_64 均可构建

```bash
./gradlew :app:assembleLeanbackArm64_v8aRelease   # TV 版
./gradlew :app:assembleMobileArm64_v8aRelease     # 手机版
```

- 产物：`app/build/outputs/apk/<变体>/release/`
- 图标资源可用 `tools/make_icons.py` 从 1024 主图一键生成
- 设置页布局可用 `tools/gen_setting_layout.py` 表驱动生成
